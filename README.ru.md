# Lingua CLI

[English](README.md) | Русский

Консольный проект на Python для перевода текста и поиска информации об английских словах.

## Статус проекта

Проект находится в разработке. Команда `word` использует
[Free Dictionary API](https://dictionaryapi.dev/), а `translate` отправляет
запросы к DeepL API Free. Обе команды доступны через `argparse` и установленную
команду `lingua-cli`. Результаты словаря оформлены через Rich; результат перевода
пока выводится обычным текстом.

## Реализованные возможности

- Запуск приложения как `lingua-cli` или через `main.py`.
- Справка по CLI и его подкомандам.
- Перевод слов и фраз на выбранный язык через DeepL API Free.
- Вывод исходного языка, определённого API перевода.
- Загрузка API-ключа DeepL из локального `.env` или переменной окружения.
- Поиск английских слов командой `lingua-cli word <word>`.
- Обработка всех словарных статей, возвращённых для одного слова.
- Вывод транскрипции, частей речи и до трёх определений для каждого значения.
- Вывод примеров, синонимов и антонимов с понятным текстом при отсутствии данных.
- Оформление словарного результата цветами и панелями Rich.
- Спиннер и счётчик прошедшего времени во время ожидания ответа сервера.
- Обработка таймаутов, ошибок соединения, общих ошибок запроса, HTTP-ошибок и
  отсутствующих в словаре слов.
- Обработка отсутствующего ключа переводчика, пустого текста, некорректного JSON
  и основных ошибок API перевода.

## Планируемые возможности

- Оформление результата перевода через Rich.
- Проверка обязательных сценариев вручную и более подробное сообщение при
  отсутствии API-ключа.

## Технологии

- **Python** — логика приложения и разделение кода на модули.
- **argparse** — аргументы командной строки и подкоманды; входит в стандартную библиотеку.
- **requests** — HTTP-запросы к внешним API.
- **python-dotenv** — загрузка локальных настроек из `.env`.
- **rich** — панели, цвета и индикатор выполнения запроса.
- **Free Dictionary API** — данные английского словаря.
- **DeepL API Free** — перевод текста и определение исходного языка.

Для перевода нужен действующий ключ DeepL API Free.

## Локальная установка

Выполни следующие команды в PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\Activate.ps1
```

Если `.venv` уже существует, используй это окружение и пропусти его создание.
Установка в режиме разработки (`-e .`) устанавливает проект и зависимости,
сохраняя связь с исходными файлами. После изменения настроек упаковки повтори
установку.

После активации окружения выведи справку по CLI:

```powershell
lingua-cli --help
lingua-cli word --help
```

Приложение также можно запустить без активации окружения:

```powershell
.\.venv\Scripts\lingua-cli.exe --help
.\.venv\Scripts\lingua-cli.exe word hello
```

## Использование

Найди информацию об английском слове:

```powershell
lingua-cli word hello
lingua-cli word programming
```

При активированном окружении ту же команду можно вызвать напрямую через Python:

```powershell
python main.py word hello
```

Словарная команда выводит панель Rich со словом и транскрипцией, а затем части
речи, определения, примеры, синонимы и антонимы. Если API возвращает несколько
словарных статей, программа обрабатывает их все.

Переведи текст на выбранный язык:

```powershell
lingua-cli translate "Hello world" --to ru
lingua-cli translate "Как дела?" --to en
```

Команда перевода отправляет запрос к DeepL и выводит определённый исходный язык,
целевой язык и переведённый текст. Вывод перевода пока не оформлен через Rich.

## Настройка

Создай `.env` в папке проекта по образцу `.env.example` и укажи в нём свой
ключ DeepL API Free:

```dotenv
TRANSLATOR_API_KEY=your_actual_deepl_key
```

Эту же переменную можно задать через окружение. Храни настоящий ключ в `.env`,
который исключён из Git; `.env.example` содержит только заглушку. Без ключа
команда перевода сообщает об ошибке. Команде `word` ключ не нужен.

## Текущая структура проекта

```text
lingua-cli/
├── main.py              # Разбор аргументов и выбор команды
├── dictionary.py        # Словарный API, разбор ответа и вывод Rich
├── translator.py        # Запрос к DeepL, разбор ответа и обработка ошибок
├── config.py            # Загрузка переменных окружения и общий таймаут
├── pyproject.toml       # Настройки упаковки и команды CLI
├── .env.example         # Образец настроек переводчика
├── .gitignore           # Локальные файлы, исключённые из Git
├── requirements.txt     # Сторонние зависимости
├── lingua_cli_TZ.md     # Техническое задание на русском языке
├── README.md            # Документация на английском языке
└── README.ru.md         # Документация на русском языке
```

`main.py` вызывает `run_word_command()` или `run_translate_command()` в
зависимости от выбранной подкоманды.

## Учебные цели

Этот проект для портфолио посвящён работе с HTTP API, разбору JSON, вложенным
словарям и спискам, обработке сетевых ошибок, проектированию CLI, оформлению
вывода в терминале, переменным окружения и разделению небольшого приложения на
модули Python.

Требования и сценарии проверки описаны в [техническом задании](lingua_cli_TZ.md).
